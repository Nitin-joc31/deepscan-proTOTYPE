Authorization required. The scan runs from the server, not your device. Use only a host and network you own or have explicit permission to assess. This tool attempts TCP connections only; it does not exploit services, try credentials, or collect banners.

Authorized host scan

The host is fixed by the operator. You cannot enter a target or scan a range.

The token is sent only to this server over the same-origin API, used for this request, and cleared from the input when the scan completes. Use HTTPS and an access-controlled deployment.

TCP port results

    An open port means the TCP connection was accepted; it does not confirm a vulnerability. Closed and timeout results can be affected by firewalls. Review open services and restrict access if they are not needed.

    For authorized defensive inventory only. This is not a CVE scanner, vulnerability verdict, or penetration test. Results are limited to the server’s network path and may not match what an external user can reach.
