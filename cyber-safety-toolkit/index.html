Review a password

Your password is checked for length and common patterns on this device.

  • •Use at least 12 characters
  • •Prefer 16 or more characters
  • •Avoid very common passwords
  • •Avoid repeating one character or short pattern
  • •Avoid obvious keyboard or number sequences

The local review is a basic checklist—not a guarantee of security or an entropy measurement. The breach lookup uses Have I Been Pwned’s k-anonymity range API.

Make a passphrase

Generate ten random words using this device’s cryptographic random-number generator.

Your new passphrase will appear here.

The phrase exists only on this page until you copy or clear it. Do not reuse a password across accounts; use a reputable password manager.

Good security habits

Prefer unique passwords

A password manager can create and remember a different long password for each account.

Turn on multifactor authentication

Add a second sign-in factor where it is offered. A passkey or authenticator is preferable to SMS when available.

Take breach alerts seriously

If an account password appears in a breach, change it on that service and anywhere else it was reused.

Educational security helper only. A clean breach lookup does not prove a password is safe, and a password check cannot replace a password manager or multifactor authentication.
